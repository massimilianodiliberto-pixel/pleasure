# Media dello scroll-scrub

Una clip per sezione del sito. Ogni file prende il nome della sezione
in cui il video **termina**.

| File | Sezione | La goccia |
|---|---|---|
| `origine.mp4` | Origine | Piccola, trasparente |
| `scienza.mp4` | Scienza | Assorbe la prima luce |
| `metodo.mp4` | Metodo | Le biotecnologie entrano: diventa tensioattivo |
| `academy.mp4` | Academy | Dorata piena, particelle in sospensione |
| `rituali.mp4` | Rituali | Satura, luminescente |
| `linee.mp4` | Linee | Entra nel flacone e lo riempie |
| `family.mp4` | Family | Tappo, pressione, crema: e' prodotto |

Per ogni clip serve anche il poster `<nome>.jpg`, che deve essere
**il primo fotogramma esatto della clip codificata**.

Vincoli: 16:9, muto, H.264/yuv420p, faststart.
Budget: <=32 MiB totali desktop.
